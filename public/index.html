Steps from iPhone

Websites can't read Apple Health, so an iPhone Shortcut sends your step count to Plate. Set it up once:

  1. Open Shortcuts → Automation → + → Time of Day. Pick a time like 10:00 PM, Daily, and choose Run Immediately. (Add a second one at 2:00 PM for updates during the day.)
  2. Add Find Health Samples: type Steps, filter Start Date is Today.
  3. Add Calculate Statistics and choose Sum of the Health Samples.
  4. Add Get Contents of URL:
    Method PUT. Under Headers add Authorization = . Request Body JSON, with a Number field named steps set to the Statistics result.
  5. Tap ▶︎ to test it. Today's steps should appear on your Dashboard.

With an Apple Watch, add the filter Source is your iPhone in step 2 so steps aren't counted twice.
